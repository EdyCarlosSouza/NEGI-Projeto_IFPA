## Sobre o projeto

O NEGI surgiu como um **trabalho acadêmico**, pensado originalmente como um sistema de gestão de estoques para pequenas empresas e organizações. Foi esse trabalho que me motivou a ir além do escopo da entrega em si e criar uma **identidade visual** e uma **landing page** para o projeto — como se ele fosse um produto real, não só um trabalho avaliativo de faculdade.

Este repositório é onde desenvolvo essa página. Por enquanto, é apenas o modelo visual/estrutural do site: a ideia é usar essa página como vitrine do produto enquanto a parte funcional (o sistema de gestão em si) é tratada separadamente.

Como é um projeto em fase de prototipagem, o conteúdo textual ainda tem trechos de placeholder (Lorem Ipsum) e algumas seções (como imagens de "Planos" e "Funcionalidades") ainda não têm o material final — vou substituindo isso conforme avanço.

---

## Tecnologias que estou usando

- **HTML5** — estrutura semântica da página
- **CSS3** — estilização (com fontes do Google Fonts: *Poppins* e *Orbitron*)
- **JavaScript** puro — interações simples, como o menu mobile
- **Bootstrap Icons** — ícones de redes sociais e interface

Não uso nenhum framework ou bundler — é HTML/CSS/JS direto, publicado via **GitHub Pages**.
